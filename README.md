## 🧱 技术栈

- **静态站点**：Jekyll 3 + kramdown（GFM）+ Rouge 代码高亮
- **主题与样式**：Hux Blog 主题、Bootstrap 3、LESS
- **能力支持**：PWA（Service Worker 离线缓存）、MathJax 数学公式、AnchorJS 文章目录、Disqus / Gitalk 评论（可选）
- **部署**：推送到 `master` 分支后由 GitHub Pages 自动构建发布

## 🖥️ 本地运行

```bash
# 安装 Jekyll（需 Ruby）
gem install jekyll jekyll-paginate jekyll-theme-slate kramdown-parser-gfm

# 启动本地预览，访问 http://127.0.0.1:4000
jekyll serve
```

新增文章时，在 `_posts/` 下创建 `YYYY-MM-DD-标题.md`，并在 YAML 头信息中填写 `category`（取值：大数据 / Java 面试 / 机器学习 / 网络与安全 / 工具与其他），文章即会自动归入首页对应分类卡片；新分类还需在 `index.html` 顶部的 `cat_list` / `icon_list` 中登记。
