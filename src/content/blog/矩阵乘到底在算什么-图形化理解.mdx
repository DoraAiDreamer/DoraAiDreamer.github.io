神经网络里到处是矩阵乘：每层 $Wx$、注意力 $QK^\top$、反向传播回传梯度……很多人会算规则（行乘列求和），却觉得它只是个机械操作。其实同一个矩阵乘，在不同语境下含义完全不同：它既能**变换空间**，又能**度量相似度**，还能**提取特征**。这篇用图形把这些含义串起来，读完你会发现它们都是一回事——**沿一个公共维度做加权汇总**。

## 1. 最朴素：一组加权求和

先看规则。若 $A$ 是 $m\times k$、$B$ 是 $k\times n$，则 $C=AB$ 是 $m\times n$，其中

$$
C_{ij}=\sum_{p=1}^{k} A_{ip}\,B_{pj}
$$

也就是：**$C$ 的第 $i$ 行第 $j$ 列，等于 $A$ 的第 $i$ 行与 $B$ 的第 $j$ 列对应相乘再相加**。

<MatdotFigure />

*图 1：高亮的 $c_{22}=a_{21}b_{12}+a_{22}b_{22}+a_{23}b_{32}$，正是"第 2 行扫过第 2 列"的加权和。注意匹配的中间维度 $k$ 在结果里消失了。*

- 维度规律：$(m\times k)(k\times n)\to (m\times n)$，**两个矩阵共有的内维 $k$ 被"加总掉"**，保留外维；
- 直觉：把 $B$ 的各行（或 $A$ 的各列）按 $A$ 给的权重做一次混合。

```python
import torch
A = torch.randn(4, 3)      # m×k
B = torch.randn(3, 5)      # k×n
C = A @ B                  # torch.matmul：m×n
print(C.shape)             # torch.Size([4, 5])
```

下面会看到，这个"加权汇总"在不同场景里换了不同的名字。

## 2. 视角一：几何变换

把 $B$ 看成空间里的一列向量（点），$A$ 看成一个变换，$y=Ax$ 就是**把每个点搬到新位置**。线性变换保持"直线仍是直线、原点不动"，它包含：

<MatgeomFigure />

*图 2：网格在变换前后发生缩放/旋转/剪切——所有点被同一个矩阵 $W$ 统一搬动。*

- **缩放**：对角矩阵，各方向拉长/压扁；
- **旋转**：正交矩阵，绕原点转角度、长度不变；
- **剪切**：矩形被推成平行四边形；
- **反射**：沿轴翻转；
- **投影**：压到低维子空间（可能丢信息）。

一个一般的矩阵可理解为"旋转 → 缩放 → 旋转"的复合（这是奇异值分解 SVD 的几何意义）。

**在神经网络里**：$x$ 是输入点，$Wx$ 把它从原空间搬到一个新空间——**训练 $W$ 就是在学习"怎么搬动特征空间"，让变换后的数据更容易被分开/拟合**。加偏置 $b$ 才能平移原点（所以 $Wx+b$ 严格叫仿射变换）。这也是为什么纯线性层不够：旋转缩放后"直的还是直的"，必须靠非线性激活把决策边界掰弯（见[神经网络教程](/blog/神经网络-人工智能的基石-从数学到pytorch/)）。

## 3. 视角二：相似度（内积）

矩阵乘的另一种用法是**批量计算两两内积**。若把两组向量分别放进行，$AB^\top$ 的第 $(i,j)$ 个元素就是向量 $i$ 和向量 $j$ 的内积：

$$
(AB^\top)_{ij} = \sum_p A_{ip}B_{jp} = a_i\cdot b_j
$$

内积在几何上衡量**两个向量方向有多接近**：夹角越小、方向越一致，内积越大（$\cos\theta$ 越大）。

<MatSimilarityFigure />

*图 3：$QK^\top$ 一次乘法算出所有 query 与所有 key 的两两内积，构成相似度矩阵；对角（自身）最相关。*

**这正是注意力机制**（见[注意力机制演进](/blog/注意力机制演进-从mha到gqa与mla/)）：

- $QK^\top$：算每个 query 和每个 key 的相关程度（图 3 的相似度矩阵）；
- softmax：把相关度归一化成权重；
- 再乘 $V$：按权重对信息加权汇总。

<Expand title="扩展：内积 vs 欧氏距离，为什么除以 √d">

- **内积/余弦**衡量"方向是否对齐"（注意力用这个）；**欧氏距离** $\lVert a-b\rVert$ 衡量"隔多远"。两者相关但不是一回事；向量归一化后内积就是余弦相似度。
- 点积的方差随维度 $d$ 增大而增大，维数高时点积数值过大、softmax 过于尖锐，所以注意力除以 $\sqrt{d_k}$ 做尺度归一化（这也是"缩放点积注意力"名字的由来）。

</Expand>

## 4. 视角三：特征/模板匹配

把 $W$ 的**每一行看成一个模板（pattern）**，那么 $Wx$ 的第 $i$ 个输出，就是输入 $x$ 和第 $i$ 个模板的内积——即"输入和这个模板有多像"：

$$
z_i = w_i^\top x + b_i
$$

一次矩阵乘，相当于**同时用很多个模板去扫描输入**，输出里记下每个模板被"触发"的程度。神经网络一层神经元在做的就是这件事：每个神经元是一个特征检测器，方向一致就强烈响应。卷积（CNN）是它的"局部窗口"版本，只在小区域做这种匹配。

## 5. 视角四：信息流动与加权组合

从列的角度看，输出 $y=Wx$ 的第 $j$ 个分量，是"输入所有分量按 $W$ 第 $j$ 列加权混合"。同一个加权汇总，也解释了：

- **图网络**：权重矩阵表示节点间连接，乘一次让信息沿边"从邻居聚合"；
- **概率转移**：马尔可夫矩阵乘概率分布，等于"每个状态按概率走一步"；
- **反向传播**：梯度沿权重从后往前传回每一层，本质也是矩阵乘（用了 $W^\top$）。

## 6. 视角五：换坐标系

同一个向量在不同基（坐标系）下表示不同。矩阵乘 $x_{\text{新}}=Mx_{\text{旧}}$ 可以理解为**换一组坐标去描述同一份数据**。把数据"换个角度看"，原本弯曲纠缠的关系可能变得简单——这和"把特征空间变换到好分类"是同一个思想，PCA/SVD 就是这种视角的代表。

## 7. 在神经网络里的"多副面孔"（收束）

同一个矩阵乘，在大模型里承担了多个角色：

| 网络中的运算 | 矩阵乘在做什么 | 视角 |
| --- | --- | --- |
| 线性层 $Wx+b$ | 把特征空间旋转/缩放；检测模板 | 几何变换 / 特征匹配 |
| 注意力 $QK^\top$ | 算 query 与 key 的相关性 | 相似度（内积） |
| 注意力 $\text{softmax}(QK^\top)V$ | 按相关度权重聚合 value | 加权组合 |
| 反向传播 $W^\top(\cdot)$ | 把误差沿权重传回 | 信息流动（逆变换） |

一句话总结：**矩阵乘 = 沿一个公共维度做加权汇总**。它既能变换空间（$Wx$）、又能度量相关性（$QK^\top$）、还能回传梯度——神经网络看起来复杂，大量计算都建立在这同一个运算之上。理解了它，再看 Transformer 就只是"矩阵乘 + 非线性 + 归一化"的反复堆叠。

## 自测（答案点击展开）

<Expand title="Q1：(m×k)(k×n) 相乘，结果是什么形状？为什么中间的 k 消失？">

结果是 $m\times n$。每个元素 $C_{ij}$ 是在中间维度 $k$ 上求加权和 $\sum_p A_{ip}B_{pj}$——这一维被"求和消掉"了，所以输出只保留两个外维 $m,n$。也可以理解为 $k$ 是"匹配/汇总"的维度。

</Expand>

<Expand title="Q2：注意力里的 QKᵀ 用的是矩阵乘的哪种含义？为什么能衡量相关性？">

用的是"内积/相似度"这一视角：$(QK^\top)_{ij}=q_i\cdot k_j$，是 query 与 key 的点积。点积等于两向量长度乘以夹角余弦，方向越一致数值越大，因此能当作"相关程度"；softmax 归一化后就是注意力权重。它和"线性层 $Wx$ 做几何变换"是同一个矩阵乘的不同解读。

</Expand>

<Expand title="Q3：为什么纯线性层做的事有限，必须要非线性激活">

矩阵乘是线性变换（旋转、缩放、剪切的复合），而线性变换的复合仍是线性的——无论叠多少层，对数据的划分边界仍是一个超平面，没法弯曲。要拟合弯曲的决策边界，必须在层间插入非线性激活函数（如 ReLU），让网络表达非线性关系。矩阵乘负责组合信息，激活负责让边界能拐弯。

</Expand>
