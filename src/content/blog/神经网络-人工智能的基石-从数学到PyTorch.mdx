今天的大语言模型（包括本博客讲的 Transformer、MoE、多模态）看起来很复杂，但它们的地基都是同一个东西——**神经网络（Neural Network）**。这篇从零讲清：神经网络用到哪些数学、基本组件长什么样、数据怎么"前向"算出预测、误差怎么"反向"传回并更新参数（反向传播），以及归一化、残差连接这些训练深层网络的关键技术。

## 0. 一个例子：直线分不开，怎么办

我们用一个贯穿全文的例子：平面上有一堆点，每个点有颜色（蓝点、橙点两类），要学一个判断"新点属于哪一类"的分类器。

**第一步尝试——用一条直线分。** 最简单的思路是在两类点之间画一条直线（这正是**逻辑回归 / 线性分类器**做的事）：直线一边判蓝、一边判橙。如果两类点大致左右分开，一条直线就能分得不错。但如果两类点像下面这样——比如橙点聚在中间、蓝点围在四周——任何一条直线都会同时切到两类点。

<NnLinearVsNonlinearFigure />

*图 0：左——线性分类器只能画一条直线（更一般地是一个超平面），遇到需要弯曲边界的分布就分不开；右——神经网络可以拼出任意形状的决策边界。*

一条直线（多维时是一个超平面）表达能力不够。但仔细想：虽然画不出弯曲的边界，我们能用直线表达"这个点是不是在某个区域里"这样**简单的判断**——比如"在左边那条线的右侧"。

神经网络的思路就是把很多个这样的"简单直线判断"组合起来：

- **线性变换**（加权求和）：每个神经元相当于在某个方向上做一次直线判断；
- **非线性激活函数**：把判断结果变成"满足 / 不满足"（0 或 1）这种非线性输出，让模型能拐弯；
- **堆叠很多层**：下一层在上一层的"简单判断"之上继续做判断。多个直线判断取交集、并集，就能拼出弯曲的、甚至包围一个区域的复杂边界（图 0 右）。

也就是说，**单个神经元画的是直线，很多个神经元分层组合，就能画出任意形状的决策边界**。这也是"神经网络"名字里"网络"的含义——很多个简单单元连在一起。

那"怎么学会这些直线的位置和组合方式"？这就要训练。训练靠一个反复迭代的闭环：

```
输入数据 → 一层层前向计算 → 得到预测 ŷ → 与真值比较、算出损失 L
                                          ↑
更新参数（优化器） ← 反向传播算梯度 ←──────┘
```

损失（分错的点带来的惩罚）一开始很大，每跑一轮就小一点，模型就这样逐步把决策边界调整到正确形状。这个闭环里的每一步，以及"为什么要归一化、残差这些技术让深网络训得动"，就是本文要讲的内容。要理解这一切，需要的数学就围绕一个问题：**给定一堆参数，怎么知道每个参数该往哪个方向调、调多少？** 这要从导数讲起。

## 1. 数学基础：从一个参数怎么调说起

数学从一个最朴素的问题开始：损失是模型参数（权重）的函数，参数稍微变一点，损失会变大还是变小？——这是一个**变化率**的问题，用微积分描述。

### 1.1 先有数：标量、向量、矩阵、张量

在问"怎么调参数"之前，先规定怎么表示数据和参数。

- 一个数叫**标量**（scalar），比如一个权重、一个坐标；
- 一组有序的数叫**向量**（vector），比如一套房子的 [面积, 楼层, 房龄]；
- 排成二维的数表叫**矩阵**（matrix），一层神经网络的权重就是一个矩阵 $W$；
- 更高维的数组合称**张量**（tensor），比如一次喂进去的一批图像（批次、通道、高、宽四个维度）。PyTorch 里的 `torch.Tensor` 就是在张量上做高效运算。

这些表示方式不是为了抽象而抽象，而是因为：一个样本有多个特征、一层有多个神经元，逐个数字写公式会写不完，用向量/矩阵能把"一堆加权求和"压成一行乘法。

### 1.2 线性变换：把加权求和写成一个乘法

先看一个神经元。它对输入的各个特征 $x_i$ 加权求和、再加偏置 $b$。按数学教材的习惯，把一个样本写成**列向量** $x$（特征数 × 1）。

这个神经元的权重 $w_1,w_2,\dots$ 也同样多，我们习惯也排成一个列向量 $w$。可两个列向量没法直接相乘——要算出"加权求和"这个标量，得把权重摆成**行向量**（1 × 特征数）去乘列向量（特征数 × 1）：

$$
z = \sum_i w_i x_i + b = w^\top x + b,\qquad
\underbrace{w^\top}_{1\times d}\ \underbrace{x}_{d\times 1} = \underbrace{z}_{1\times 1}
$$

这里的转置 $w^\top$ 只是把权重列向量"放倒"成行向量，好让矩阵乘法的维度对得上，得到一个标量 $z$。

一层有很多个神经元时，每个神经元都有自己的一组权重。把每个神经元那一行 $w^\top$ 上下摞起来，就得到权重矩阵 $W$（形状"神经元数 × 特征数"，每一行是一个神经元的权重）。一次矩阵乘法 $Wx$ 就同时算出所有神经元的输出：

设这一层有 $n$ 个神经元，第 $i$ 个神经元的权重是（列向量）$w_i$、偏置 $b_i$，输出 $z_i=w_i^\top x+b_i$。把每个神经元的 $w_i^\top$ 作为一行摞起来，就得到权重矩阵 $W$：

$$
W=\begin{bmatrix}
\ \longleftarrow\ w_1^\top\ \longrightarrow\ \\
\ \longleftarrow\ w_2^\top\ \longrightarrow\ \\
\vdots
\end{bmatrix},\qquad
\begin{bmatrix} z_1\\ z_2\\ \vdots \end{bmatrix}
= Wx + b
$$

即 $W$ 的第 $i$ 行就是第 $i$ 个神经元的权重行 $w_i^\top$；一次矩阵乘法就同时算出所有神经元的输出。$z=Wx+b$ 这样的运算叫**线性变换**——对输入做“各维度按比例缩放后相加”，几何上就是旋转、缩放、平移。它有个关键性质：**线性变换的复合仍然是线性的**（这正是后面必须加非线性激活的原因）。

**那 PyTorch 里为什么是 $xW^\top$？** 工程实现中，一批样本通常按**行**堆成矩阵 $X$（形状 `(batch, 特征数)`，一行一个样本），存储和批量计算都更方便。为了和“行是样本”对齐，`nn.Linear` 把权重存成 `weight.shape = (输出维度, 输入维度)`（也就是数学里 $W$ 的形状），计算时做

$$
Z = X W^\top + b
$$

多出的那个转置 $^\top$，只是因为样本 $X$ 按行存放、而数学里 $W$ 是“每行一个神经元”——转置是为了让矩阵维度对得上；本质上每个样本算的还是 $z=Wx+b$。

| 数学（列向量约定） | PyTorch |
| --- | --- |
| 一个样本是列向量 $x$，一层算 $z=Wx+b$ | 一批样本按行堆：`x.shape=(batch, in_features)` |
| $W$ 每行一个神经元，形状 (out × in) | `nn.Linear(in_features, out_features)` 的 `weight` 形状正是 `(out, in)` |
| 每个样本 $z=Wx+b$ | `F.linear(x, weight, bias)`，内部即 $xW^\top+b$ |

<Expand title="扩展：矩阵乘的几何含义（线性变换）">

把 $Wx$ 看成"矩阵 $W$ 对空间里的点 $x$ 做一次几何变换"。线性变换保持"直线还是直线、原点不动"，它能做的事包括：

- **缩放**：对角矩阵把各方向拉长/压扁（如整体放大 2 倍）；
- **旋转**：旋转矩阵让向量绕原点转一个角度（长度不变）；
- **剪切**：一个方向的偏移随另一个方向变化，矩形被推成平行四边形；
- **反射**：沿某条轴翻转；
- **投影**：把高维向量压到低维子空间（可能丢信息）。

一个一般的矩阵可以理解为"旋转 → 缩放 → 旋转"的复合（这就是奇异值分解 SVD 的几何意义）。

放到神经网络里：$x$ 是输入特征点，**学习权重 $W$，本质上是在学习怎么旋转、缩放、翻转特征空间**，让变换后的点更容易被分类/拟合；加偏置 $b$ 则额外做了"平移"（线性变换本身不能平移，所以 $Wx+b$ 严格叫仿射变换）。这也解释了为什么纯线性层能力有限——旋转缩放后直的还是直的，决策边界弯不了，需要非线性激活来"掰弯"。

</Expand>

### 1.3 导数与梯度：参数调一点，损失变多少

回到那个朴素问题：把权重 $w$ 调大一点点，损失 $L$ 是升还是降？

一元函数里，这个变化率就是**导数** $\dfrac{dL}{dw}$：在当前点，$w$ 每增加一个小量，$L$ 平均变化多少。

- 若 $\dfrac{dL}{dw} > 0$：$w$ 增大会让损失变大，那要降低损失就该**减小** $w$；
- 若 $\dfrac{dL}{dw} < 0$：$w$ 增大让损失变小，就该**增大** $w$。

网络里的参数是成千上万个。对每个参数分别求一次偏导数 $\dfrac{\partial L}{\partial w_i}$，把它们按顺序排成一个向量，就叫**梯度** $\nabla L$。梯度指向"损失增长最快"的方向，所以让损失下降的方式是朝梯度的反方向迈一步：

$$
w \leftarrow w - \eta\,\frac{\partial L}{\partial w}
$$

这就是**梯度下降**，$\eta$ 是学习率（迈多大），第 6 节细讲。

### 1.4 链式法则：误差怎么"追"到每个参数

前面是"损失直接依赖输出层参数"的简单情况。但神经网络有很多层，损失看起来离靠前层的参数很远，怎么知道它们该怎么调？

答案是**链式法则**：复合函数的导数等于各段导数相乘。若 $y=f(u)$、$u=g(x)$，则

$$
\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}
$$

在神经网络里，损失经过"激活→上一层线性→再上一层……"一连串函数才到输入。把这条链路上每一段的变化率**乘起来**，就能从损失一路追溯到任意一个参数：

- 这一步出了误差，先影响紧挨着的那一层参数；
- 那一层的误差又通过它的输入（上一层的输出）继续往前影响——如此层层传递。

**反向传播本质上就是用链式法则，从损失出发自动算出每个参数的梯度。** 它没有什么神秘，只是把"逐层求变化率"这件麻烦事系统化了。

<Expand title="扩展：为什么要求运算可微，雅可比是什么">

- 反向传播要逐层求导，所以网络里的运算（包括激活函数）都得**可微**（或几乎处处可微）。ReLU 的导数极其简单（输入为正导数是 1、为负是 0），既保留非线性又不增加反向计算量，因此非常受欢迎。
- 当输入和输出都是向量时，"输出对输入逐元素的偏导"组成一个矩阵，叫**雅可比矩阵（Jacobian）**。矩阵乘法 $z=Wx+b$ 对 $x$ 的雅可比就是 $W$（对 $W$ 的雅可比和 $x$ 有关），所以反向传播也能高效地用矩阵运算批量实现，而不用逐个参数算。

</Expand>

## 2. 基础神经网络组件

### 2.1 神经元：线性变换 + 激活

一个"神经元"做两件事：

$$
z = \sum_i w_i x_i + b = w^\top x + b,\qquad a = \sigma(z)
$$

先把输入加权求和（$z$），再过一个**激活函数** $\sigma$ 得到输出 $a$。

<NnForwardFigure />

*图 1：左边是一个神经元——加权求和（$z=w\cdot x+b$）再过激活（$a=\sigma(z)$）；多个神经元组成一层、多层堆叠成网络（MLP），层间每条连线对应一个权重。*

### 2.2 激活函数（非线性的来源）

| 激活函数 | 公式（简化） | 特点 |
| --- | --- | --- |
| Sigmoid | $\sigma(z)=\dfrac{1}{1+e^{-z}}$ | 输出 (0,1)，但深层易梯度消失 |
| Tanh | $\tanh(z)$ | 输出 (-1,1)，仍会梯度消失 |
| **ReLU** | $\max(0,z)$ | 负数置 0，**导数简单（正为 1、负为 0）**、最常用 |
| GELU / SiLU | 平滑版 ReLU | Transformer / 现代网络常用（见归一化文章） |

**为什么必须有激活函数？** 如果只有线性层，叠再多层，整体等价于一个线性变换（线性的线性还是线性），等于没堆叠。激活函数引入非线性，网络才能"拐弯"、拟合复杂形状。

### 2.3 层、MLP 与 FFN：知识存在哪里

一层有很多个神经元（每个有自己的 $W$、$b$，合起来就是一个权重矩阵）。**多层感知机（MLP）** 就是"输入层 → 若干隐藏层 → 输出层"的堆叠。

**它为什么能"记住"特征？** 可以这样理解：每个隐藏神经元是一个特征检测器（4.2 节讲过，权重是一个模板）。隐藏层的神经元被训练成"看到某个模式就强烈响应"，这个模式由它的**权重**表示——权重在训练中学成什么形状，就相当于网络把学到的"什么是边缘、什么是某个词的关联"等知识**记录在了权重里**。一层层组合，浅层记录简单模式、深层记录由简单模式构成的抽象概念（图像里可能是 边缘 → 部件 → 物体）。

这个"两层线性 + 中间一个非线性"的结构，在大语言模型里有个专门的名字——**前馈网络（FFN / Feed-Forward Network）**。Transformer 的每个 Block 都是"注意力 + FFN"：注意力负责**在 token 之间移动信息**，FFN 则像一个存储/加工单元，把注意力混合后的信息做非线性变换、**写入参数并逐步积累"知识"**（参数量大头也通常在 FFN）。关于 Transformer 里 FFN 的具体位置，见[图解 Transformer](/llm/)。

> 卷积神经网络 CNN 是为图像设计的特殊网络：它用"卷积"在局部窗口里共享权重，大幅减少参数量并利用空间结构；它的训练原理（前向+反向）和本文完全一样，只是线性层换成了卷积层。这里不展开。

## 3. 前向传播（Forward）

讲完"一个神经元"和激活函数，接下来看它们怎么串起来。**前向传播**就是数据从输入经过每一层的"线性+激活"，一步步算到输出的过程。约定用上标 $[l]$ 表示第几层、$a^{[0]}=x$ 是输入，则第 $l$ 层：

$$
z^{[l]} = W^{[l]} a^{[l-1]} + b^{[l]},\qquad a^{[l]} = \sigma\!\left(z^{[l]}\right)
$$

最后一层的输出 $a^{[L]}=\hat{y}$ 就是预测。

**PyTorch 实现一个 2 层 MLP 并做前向：**

```python
import torch
import torch.nn as nn

torch.manual_seed(0)
batch, in_dim, hidden, out_dim = 4, 10, 32, 2

# 一个 2 层 MLP：输入 → ReLU 隐藏层 → 输出
model = nn.Sequential(
    nn.Linear(in_dim, hidden),   # W1 x + b1
    nn.ReLU(),                   # 激活（非线性）
    nn.Linear(hidden, out_dim),  # W2 h + b2 → 输出 logits
)

x = torch.randn(batch, in_dim)    # 一批 4 个样本，每个 10 个特征
logits = model(x)                # ← 前向传播：直接调用就得到预测
print(logits.shape)              # torch.Size([4, 2])
```

`nn.Linear` 就是线性变换 $Wx+b$（内部按行向量算 $xW^\top+b$，见 1.2 的说明）；把模块像积木一样串起来，`model(x)` 就自动完成了整个前向。

## 4. 损失函数："学"的目标

损失函数 $L$ 衡量预测 $\hat{y}$ 和真实标签 $y$ 的差距，必须**可微**（才能求导）。常见两种任务：

| 任务 | 损失函数 | 直觉 |
| --- | --- | --- |
| 回归（预测数值） | **均方误差 MSE**：$L=\frac{1}{n}\sum(\hat y-y)^2$ | 预测值和真值差多少，平方后平均 |
| **分类（本文的例子）** | **交叉熵 Cross-Entropy** | 预测的概率分布和真实标签的差距：分错的点惩罚大 |

我们前面的"把两类点分开"是分类任务，用**交叉熵**——把蓝点判成橙点（或反过来）会带来损失，分得越对损失越小。

损失是一个标量数字——训练的全部目标就是让它变小。

```python
y = torch.randint(0, out_dim, (batch,))          # 4 个样本的真实类别（0 或 1）
loss_fn = nn.CrossEntropyLoss()
loss = loss_fn(logits, y)                        # 前向算出来的 logits 与真值比较
print("loss =", loss.item())
```

## 5. 反向传播（Backpropagation）

前向传播能得到预测、损失能衡量"错得有多离谱"，但还缺最关键的一步：**怎么知道每个权重该往哪个方向改？** 这正是第 1 节铺垫的梯度和链式法则派上用场的地方。**反向传播**先前向算出损失 $L$，然后从损失出发，用链式法则把"损失对每个参数的梯度"一层层往回算，供下一步更新参数。

<NnBackpropFigure />

*图 2：前向（上，蓝色）从 $x$ 算到损失 $L$；反向（下，红色）从 $L$ 出发，用链式法则把梯度 $\partial L/\partial W$、$\partial L/\partial b$ 传回每一层，供优化器更新。*

**为什么要"反向"传？** 损失只直接依赖最后一层，前面的权重看不见损失；但通过链式法则——"这层的误差 → 影响它上一层 → 再影响更上一层"——就能把责任一路追溯到每个参数，知道**每个权重该往哪个方向调、调多少**。

<Expand title="扩展：反向传播公式逐层推导">

记 $\delta^{[l]}=\dfrac{\partial L}{\partial z^{[l]}}$（第 $l$ 层"误差信号"，列向量），前向为 $z^{[l]}=W^{[l]}a^{[l-1]}+b^{[l]}$、$a^{[l]}=\sigma(z^{[l]})$。从最后一层 $L$ 开始：

1. **输出层误差**：损失对输出的梯度，乘上激活导数
$$
\delta^{[L]}=\frac{\partial L}{\partial a^{[L]}}\odot\sigma'(z^{[L]})
$$

2. **该层参数的梯度**（列向量约定：$W$ 每行一个神经元）
$$
\frac{\partial L}{\partial W^{[l]}}=\delta^{[l]}\,(a^{[l-1]})^\top,\qquad
\frac{\partial L}{\partial b^{[l]}}=\delta^{[l]}
$$

3. **把误差传到上一层**（权重矩阵转置回传，再乘上一层激活导数）
$$
\delta^{[l-1]}=\Big((W^{[l]})^\top\,\delta^{[l]}\Big)\odot\sigma'(z^{[l-1]})
$$

4. **重复**步骤 2–3，$\delta^{[L]}\to\delta^{[L-1]}\to\cdots\to\delta^{[1]}$，每一层的 $W,b$ 梯度随之算出。

注意 $\dfrac{\partial L}{\partial W^{[l]}}=\delta^{[l]}(a^{[l-1]})^\top$ 里的转置方向：因为 $W^{[l]}$ 是"神经元数 × 特征数"（列向量约定），误差 $\delta^{[l]}$（神经元数×1）要乘上输入的行向量 $(a^{[l-1]})^\top$（1×特征数）。

每一层只需本地信息（自己的输入 $a^{[l-1]}$、权重和上游传下来的 $\delta^{[l]}$），逐层算下去即可——这就是反向传播能自动、快速处理百万参数的原因。

</Expand>

**PyTorch 里反向传播是自动的**（autograd）：

```python
model.zero_grad()        # 清空上一轮的梯度（否则会累加）
loss = loss_fn(model(x), y)   # 前向
loss.backward()          # ← 反向传播：自动算出所有参数的 .grad
for name, p in model.named_parameters():
    if p.grad is not None:
        print(name, "梯度形状:", p.grad.shape)   # 每个权重都有了自己的梯度
```

可以做个对照实验：先用 PyTorch 自动求，再对一个简单神经元**手算梯度**验证链式法则——两者结果一致，说明"自动微分"背后就是在做我们上面推导的链式法则。

## 6. 优化器：用梯度更新参数

反向传播给出了"每个参数的梯度"，训练闭环还差最后一步——**用这些梯度真正改参数**。更新参数的规则叫**优化器（optimizer）**。最基础的是**梯度下降**：

$$
W \leftarrow W - \eta \frac{\partial L}{\partial W}
$$

梯度指向"损失上升最快"的方向，所以减去梯度×**学习率 $\eta$**，就朝损失下降的方向走一小步。

- **学习率 $\eta$**：每步迈多大。太大可能越过最优点、来回震荡；太小则学得很慢。
- **SGD**：每批数据走一步；**Momentum**：带"惯性"，冲出小坑、更平滑；**Adam**：自适应地为每个参数调整步长，是当前最常用的默认选择。

```python
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

for step in range(100):
    optimizer.zero_grad()          # 1. 清空梯度
    loss = loss_fn(model(x), y)    # 2. 前向 + 算损失
    loss.backward()                # 3. 反向传播算梯度
    optimizer.step()               # 4. 用优化器更新 W、b
    if step % 20 == 0:
        print(f"step {step}, loss {loss.item():.4f}")   # 损失逐步下降
```

这 4 步（清零 → 前向 → 反向 → 更新）就是所有深度学习训练循环的骨架，Transformer 的训练也一样。

## 7. 归一化技术（Normalization）

前面的梯度下降能工作有个前提：梯度能稳定地从损失传到每一层。可一旦网络加深，会出现新问题——每层输入的分布随前面参数变化而漂移（**内部协变量偏移**），梯度容易爆炸或消失、收敛很慢。**归一化层**把每层的输入拉回稳定的尺度（均值 0、方差 1 附近），再用可学习参数还原表达力，让训练更深、更稳、更快。

两种最常见的归一化，**区别在于"沿哪些维度统计"**：

- **BatchNorm（批归一化）**：沿 **batch（跨样本）**、对同一个特征维度统计均值/方差——像"这一列特征在所有样本上归一化"，CNN 常用。训练时维护滑动统计量，推理时使用。
- **LayerNorm（层归一化）**：对**每个样本内部、跨所有特征**统计——不依赖 batch 大小，天然适合变长序列，是 **Transformer / 大模型的标配**。

```python
# BatchNorm：常用于 CNN / 全连接（沿 batch 维度）
bn = nn.BatchNorm1d(num_features=hidden)
# LayerNorm：Transformer/RNN 标配（沿每个样本的特征维度）
ln = nn.LayerNorm(normalized_shape=hidden)
```

现代大模型在此基础上用了更省的 **RMSNorm**（不减均值、只按均方根缩放），以及 Pre-Norm/Post-Norm 结构——详细对比和 Pre-Norm 为什么让深层可训练，见 [归一化：从数学到工业实践](/blog/归一化-从数学到工业实践/)。

## 8. 残差连接（Residual）

归一化稳住了每层的数值分布，另一个让深网络"训得动"的关键是**残差连接**。理论上网络越深表达力越强，但实际中太深反而更差（**退化问题**）：梯度在层层反传中不断相乘，即便有归一化，也容易消失或爆炸，底层很难学到东西。

**残差连接（residual / skip connection）** 的做法极简：不直接学 $H(x)$，而是学"在输入基础上的增量"——

$$
\text{输出} = x + F(x)
$$

让信息/梯度**沿一条"高速公路"直接跨层传过去**（$x$ 这条支路恒等、不经过 $F$）。

<Expand title="扩展：残差为什么有效">

- 反传时，损失对 $x$ 的梯度有一条 $\frac{\partial (x+F(x))}{\partial x}=1+\frac{\partial F}{\partial x}$ 的通路，其中那个 **1 保证梯度至少能原样穿过这一层**，不会被反复乘小数字而消失——这就是"残差高速路"。
- 极端情况下，如果 $F(x)$ 什么都不用做，$F\to 0$，网络至少能保持输入（恒等映射），不会比浅网络更差。所以堆得深也"不伤身"。
- Transformer 每个 Block 里的"注意力 + 残差"、"FFN + 残差"（以及 Pre-Norm）正是这个机制，它让几十上百层的大模型可以稳定训练（见 [图解 Transformer](/llm/)）。

</Expand>

```python
class ResidualBlock(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.fc1 = nn.Linear(dim, dim)
        self.act = nn.ReLU()
        self.fc2 = nn.Linear(dim, dim)
        self.norm = nn.LayerNorm(dim)

    def forward(self, x):
        h = self.fc2(self.act(self.fc1(self.norm1(x))))  # 变换 F(x)
        return x + h                                    # ← 残差：输入直接加回来
```

归一化 + 残差 + 良好初始化，是把神经网络从"几层"堆到"上百层"的三大支柱。

## 9. 一个完整可跑的例子

到这里，前向、损失、反向、优化器、归一化、残差都分开讲过了。这个例子把它们**拼进同一个训练循环**——用一个带 LayerNorm 和残差的 MLP，在简单分类任务上跑一遍，你会发现代码里处处都是前面讲过的部件。

```python
import torch
import torch.nn as nn

torch.manual_seed(0)

# 造一个简单的二分类数据：两类点各在一个中心附近
n = 400
X = torch.randn(n, 8)
y = (X[:, 0] + X[:, 1] * 0.5 - X[:, 2] > 0).long()

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(8, 64)
        self.norm1 = nn.LayerNorm(64)
        self.act = nn.ReLU()
        self.fc2 = nn.Linear(64, 64)
        self.norm2 = nn.LayerNorm(64)
        self.out = nn.Linear(64, 2)

    def forward(self, x):
        h = self.act(self.fc1(self.norm1(x)))    # 第 1 层：归一化 → 线性 → 激活
        r = self.act(self.fc2(self.norm2(h)))    # 第 2 层
        h = h + r                                # 残差连接
        return self.out(h)

model = Net()
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

# 简单划分训练/测试
Xtr, ytr = X[:320], y[:320]
Xte, yte = X[320:], y[320:]

for epoch in range(50):
    model.train()
    optimizer.zero_grad()
    loss = loss_fn(model(Xtr), ytr)   # 前向
    loss.backward()                   # 反向传播
    optimizer.step()                  # 更新参数

model.eval()
with torch.no_grad():
    acc = (model(Xte).argmax(1) == yte).float().mean().item()
print(f"测试准确率: {acc:.2%}")        # 通常能到 95%+
```

这段代码里可以找到本文所有概念：`nn.Linear`（线性变换）、`ReLU`（激活）、前向得到 logits、`CrossEntropyLoss`（损失）、`loss.backward()`（反向传播）、`Adam`（优化器）、`LayerNorm`（归一化）、`h + r`（残差）。**它们也是 Transformer 的积木**——把"全连接层"换成"自注意力 + FFN"，就是大语言模型的骨架。

## 10. 小结与自测

神经网络的完整训练闭环：**数据前向传播（线性+激活层层计算）→ 损失函数衡量误差 → 反向传播用链式法则算梯度 → 优化器按梯度更新参数**，而归一化和残差连接让这个过程在很深的网络里依然稳定。

- **核心数学**：矩阵乘法（线性变换）、梯度（参数怎么影响损失）、链式法则（梯度怎么层层回传）。
- **核心组件**：神经元（线性+激活）、激活函数（非线性来源）、MLP（堆叠）。
- **深层可训练的支柱**：归一化（稳定分布）、残差连接（梯度高速路）、合理的优化器/初始化。

<Expand title="自测 Q1：为什么网络里必须有激活函数，全是线性层会怎样？">

全是线性层时，无论叠多少层，输出对输入始终是一个线性变换（线性函数的复合还是线性），等价于只有一层，无法拟合非线性关系（比如弯的决策边界）。激活函数引入非线性，多层网络才能表示任意复杂的函数。

</Expand>

<Expand title="自测 Q2：反向传播解决什么问题？为什么能高效算百万参数的梯度？">

它解决"损失对每个参数的梯度是多少"，从而知道每个权重该往哪个方向调。高效的原因是：用链式法则把计算分解成**逐层的局部计算**——每层只需自己的输入和从上游传回的梯度，中间结果在前向时缓存、反向时复用，整体代价大约是一次前向的 2 倍，而不需要对每个参数都单独重新求导。

</Expand>

<Expand title="自测 Q3：残差连接为什么能让很深的网络也训得动？">

残差块输出 $x+F(x)$，反传到该块时梯度是 $1+\partial F/\partial x$——那个恒等项 1 让梯度至少能原样穿过这一层，不会因层层相乘而消失，梯度可以从损失直达最底层；同时若某层没必要存在，$F\to 0$ 即退化为恒等，深层网络至少不比浅层差。这就是上百层 Transformer 可训练的关键之一。

</Expand>
