两类层的内部结构

GDN 层与 Full Attention 层都采用 Pre-Norm + 残差结构,但注意力子层完全不同: 前者是带卷积状态(conv)和时序状态(temporal/SSM)的线性注意力,后者是带 RoPE 的 GQA 全注意力。两者之后都接 MoE/MLP。

⚠️ 前缀缓存的 block size = 1536
由于 hybrid 对齐(Ascend 要求 SSM state 精确填满一个 attention block 的 K 区), 在 TP=2、bf16 KV、SSM fp32 时, cache_config.block_size = 1536 tokens。 短于 1536 token 的公共前缀无法形成完整 block 被缓存,因此短前缀高重复场景建议 --no-enable-prefix-caching。TP=8 时因 KV head 复制降至 768; 310P 上用 --mamba-ssm-cache-dtype float16 可降至 768。
推导见 docs/notes/04_attn_block_size_mamba_config.md。
